# Privacy

QuietTube adds local preference storage and bounded local diagnostic counters/capture. No automatic diagnostic upload or new analytics endpoint is added by this project. YouTube, Google sign-in, LiveContainer, GitHub and any IPA host have their own network and data practices; this is not an offline/privacy guarantee for those applications.

Detailed feed/template capture is optional. The everyday presets turn it off, but existing saved preferences are not silently changed on upgrade. Preparing a support test explicitly enables it. Reports may contain internal class/template identifiers, event times, flags and bounded error categories/codes. Raw payloads, account credentials, video-ID fields and signed URL fields are not intentionally printed. Lexically extracted names are diagnostic clues, not a privacy-proof parser; review before sharing.

Detailed event rings and template capture are in memory; restart resets them. Preferences persist in the guest's defaults. Clear template capture clears that capture, not all counters/preferences. Manually copied reports or screenshots can remain wherever you share them. Never post credentials, cookies, tokens, personal account information or unreviewed full captures.
